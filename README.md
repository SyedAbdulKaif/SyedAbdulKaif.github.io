# Kaif — DevOps Portfolio

A responsive, dark-themed personal portfolio built with HTML, CSS and JavaScript.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Before publishing
- Replace the LinkedIn and GitHub homepage links in `index.html` with your actual profile URLs.
- Replace `your-email@example.com` with your professional email.
- Confirm your education status and graduation year.
- Add real repository links, screenshots and READMEs as projects are completed.
- Only list certifications after earning them.

## Publish with GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Your site will be available at `https://YOUR-USERNAME.github.io/` after deployment finishes.

## Current portfolio content
Project cards are intentionally labelled as learning labs / in progress. Update them with verified work as you complete each project.
